## Failure

`nixos-install` stopped evaluating the generated configuration (journal 02:53:25):

```
error: attribute 'boot.loader.grub.enable' already defined at /mnt/etc/nixos/configuration.nix:15:3
       at /mnt/etc/nixos/configuration.nix:199:3
```

**Root cause** (#320): `nixos-generate-config` writes the extlinux loader lines because the running SD image has `/boot/extlinux`. pre-nixos's managed block wrote the same attributes into the same file, and in one attribute set that is a Nix parse error.

**Fixed in 0.20.1:**
- The Pi's loader is declared in its own module, `/etc/nixos/pre-nixos-boot-loader.nix`, with `mkForce`.
- New permanent tests run against the generator's **real** output for the extlinux, GRUB and EFI cases:
  - pytest;
  - the flake checks `installed-configuration-parses` and `installed-rpi-boot-loader`.
- Shown before the fix: the pytest test and both flake checks fail on the old code, the parse check with this same error.
- The rendered CM4 configuration also evaluates as a whole system (`system.build.toplevel.drvPath`).

## Other anomalies in this run (recorded, not fixed here)

1. **Undervoltage:** `hwmon hwmon1: Undervoltage detected!` appears about every 2–10 s from 20 s onward. This is the board's power supply, not software. It could cause NVMe or SD errors under load, so it should be fixed before the next attempt.
2. **CMA exhausted:**
   - What was seen: `cma: __cma_alloc: linux,cma: alloc failed, req-size: 256 pages` (and 512 pages) at 56 s, during disko, with 176 of 16384 pages free.
   - Hypothesis, unproven: the NVMe driver's 64 MiB host memory buffer (`allocated 64 MiB host memory buffer`) takes nearly all of the 64 MiB CMA pool. Who made the failed allocations is unknown.
   - The run was not visibly harmed, but the installed system will have the same pool. Task queue item 20.
3. **Log order:** after the failure, the journal repeats `Starting automatic NixOS installation at …` after `Auto-install failed: nixos-install`. Task queue item 21.
4. **The failure was not obvious at the console:** the user had to look for it. This is the existing task queue item 16 (auto-install status in the TUI).
5. **The 29-minute image build** on the user's N355: not yet analysed; the U-Boot and firmware builds are candidates. Task queue item 22.
