## Failures

1. **Two DHCP clients on the installed `lan`** → #326.
   - The log shows both `Started Network Management.` (networkd, from the managed block) and `Started Network Manager.`, with `WPA Supplicant`.
   - NetworkManager comes from `networking.networkmanager.enable = true;`, which `nixos-generate-config` writes into every `configuration.nix`.
   - **Fixed in 0.22.1:** `/etc/nixos/pre-nixos-network.nix` sets `mkForce false`.
   - Evidence: the flake check `installed-network-single-dhcp-client` failed before the fix (`{"networkd":true,"networkmanager":true}`) and passes after it. The full rendered installed configuration evaluates with NetworkManager, its unit and `wpa_supplicant` all off.
2. **Every installer broadcast appeared twice on serial** → #327.
   - `get_console_paths` always appended `/dev/console`, which is the primary console and already in the active list. This was invisible while `tty0` was primary.
   - **Fixed in 0.22.1:** `/dev/console` is now only the fallback, used when no active console is known.
   - A second, separate source in the installed system is recorded on #327: the announce unit's `StandardOutput=journal+console`, plus its direct `/dev/console` write.

## Other observations

- **The install start time is right this time** (14:20:31Z); the clock had synced. This is the opposite of attempt 2 (task queue item 24).
- **Still present:**
  - undervoltage, 34 warnings (item 23);
  - CMA exhaustion during provisioning, and once at the installed system's boot (item 20);
  - the `26.05pre-git` label (item 25);
  - `ERROR: reserving fdt memory region failed … -17` (item 26).
- **Wiping the NVMe:** deleting the partitions and zeroing the first 16 MiB was not enough. Detection still found signatures, presumably the backup GPT. Task queue item 27 covers the hazard of stale signatures inside the old partition areas.
- **Booting the SD card while NVMe holds a system** needs `setenv boot_targets mmc0; bootflow scan` at the U-Boot prompt (item 28).
- **`uptime` showed 219 days on the installer.** That is the 2026-03-17 built-in epoch to now, so probably a boot time recorded before the clock was set. Not investigated.
