## Result
- The fail-fast fix works: `Unit pre-nixos entered the failed state`. There was no 600 s wait.
- The same product failure occurred: `cleanup verification failed: lingering md/LVM devices remain`.
- **The action log was not captured:** `/var/log/pre-nixos/actions.log: No such file or directory`.
  - Root cause: `logging_utils.log_event` writes nothing unless `PRE_NIXOS_LOG_EVENTS` is set (`_logs_enabled`).
  - Neither the service nor the test sets it. The path itself was correct.
  - I had assumed the file was written; the experiment showed it is not.

## Follow-up
- The scenario now sets `PRE_NIXOS_LOG_EVENTS=1` together with `PRE_NIXOS_FORCE_CLEANUP=1` before the forced run.
- The harness now explains an absent log.
- Re-run to name the lingering devices.
